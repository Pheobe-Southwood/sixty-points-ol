# 纯规则引擎独立包 + 服务器权威个人视图

可测试性是一等需求（以单元测试为主）。规则引擎做成 pnpm workspace 下的独立包 `packages/engine`：零依赖、纯 TypeScript、显式状态进出（reducer 风格 `applyAction(state, seat, action)`），洗牌用注入的 RNG 以便复现。SvelteKit 应用（`apps/web`）只做薄壳：服务器端持有完整权威状态、按玩家过滤生成 **个人视图**；客户端仅消费视图并复用引擎的纯函数做合法出牌提示。

理由：引擎与框架/IO 隔离后，规则（顺子、结构优先、杀牌、结算、升级、结束条件）可以全量表驱动 + 属性测试覆盖，不需要起服务器或浏览器；个人视图在服务端过滤保证隐藏信息（他人手牌、底牌）绝不泄漏到客户端负载。

后果：引擎类型即共享契约（单一事实来源）；SQLite 持久化的是引擎完整状态 JSON + 追加事件表，重启后可无缝续局。
