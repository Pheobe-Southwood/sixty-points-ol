# 级别属于座位，身份可以换人

**座位** 是进度的锚点：引擎状态按座位索引（`levels[seat]`、`hands[seat]`、`captured[seat]`、战报里的升级也是座位），所以人可以在任何时候 **离座** —— 座位空出、本副不废、停在空座上等人补位，补位者接下该座位的手牌与级别继续打完这一副。身份与座位因此解耦：**改名与换身份只允许在不在座时进行**（身份是全局的，判据是「没占着任何一张桌的座位」），改名后 **凭据串** 随名字重签、旧串立即失效。

理由：三个人凑一局，有人临时要走是常态；把级别挂在身份上，换人就只能二选一 —— 要么重开一局，要么让打输的升级落空。而把改名/换身份限制在不在座时，本副内座位上的名字保持稳定，也顺带堵住「换了身份但旧身份还占着座位」的幽灵占位。

后果：`claim(name)` 不再对已存在的名字返回那条身份（否则输入别人的名字就能接管他的座位与手牌），撞名一律 400；发牌与开新对局每次都要求三人到齐（座位可能被离座腾空，不能只在首副校验）；大厅的「我的同桌」既列在座的桌也列 **观战** 的桌，离座后不必重新找链接；战报与结算按座位渲染**当前**名字，不保存历史名字。
