# `/rules` 新手教程 · 重写稿

## 0. 起源：为什么会有六十分

一言以蔽之，六十分是**桥牌**、**双升 (八十分/拖拉机)**、**斗地主**的融合版。如果你接触过**五十 K**、**掼蛋**，你可能也会见到一些熟悉的概念。

六十分给希望拥有双升/桥牌一般体验，但只能凑出 **3 个人**的牌友提供一种新玩法。

## 1. 目标：六十分的胜败关键

六十分的**每一副都是「1v2」**。叫到牌的那个人当**庄家**，另外两家临时联手当**闲家**。一副牌的胜败关键就是：

> **庄家抓到的分，有没有达到他叫出去的分数。**

如果够了，庄家升级；如果不够，两家闲家升级。

所以，从全局尺度看，最终任务是**升级**；从单局尺度看，最终任务是**得分**。

一副牌一共有四个阶段：

```widget
阶段条 StageBar · 4 步，可点跳到对应小节（沿用现有 TOC 锚点样式）
  ① 叫牌 → ② 埋底 → ③ 打牌 → ④ 结算
```

- **发牌**：54 张，每人 17 张，剩 3 张扣着不动，叫「**底牌**」。
- **座次**：**庄家出第一轮**，之后每轮由上轮的赢家先出。
- 第一个发牌的人也**先叫牌**，每副轮换。
- 一共 17 轮，三家每轮各出一次。

每个人有**独立的级别**：从 `2` 开始一级一级往上，爬完 `A` 再套圈进入下一轮的 `2`，记作 `5(+0)`、`A(+1)`、`5(+2)`。

## 2. 分：总计 100 分

全场一共 **100 分**，只藏在三种牌里：

```widget
CardRow size=md · 三张代表牌
  ♥5 · ♦10 · ♠K
```

| 牌 | 分 |
| --- | --- |
| 5 | **5** |
| 10 | **10** |
| K | **10** |
| 其他（含大小王） | 0 |

四张 5 = 20 分、四张 10 = 40 分、四张 K = 40 分，加起来正好 100。

一副牌打完，这 100 分只会落在三个地方：

> **庄家赢下的轮里的分 ＋ 闲家赢下的轮里的分 ＋ 底牌那 3 张的分 ＝ 100**

注意：**底牌**的分不算在任何人的轮里，只在最后算账时按倍数记到庄家头上（第 5 节）。

```widget
一墩三张 + 标注「这一轮的分记给赢家」
  ♣K ♥5 ♠7
```

## 3. 主牌：一副 18 张的大牌

**主牌压副牌**，这是这副牌唯一真正的强弱关系：只要一轮里能凑出跟对手**同样张数**的主牌连牌，就能直接赢下来，不用比大小。

哪些牌算主牌？三部分：

1. **大小王** —— 永远算主牌，而且永远是最大的两张。
2. **级牌** —— **点数等于庄家级别的那四张**，什么花色都算。示例庄家级别是 5，所以四张 5 全是主牌。
3. **主花色** —— 叫牌叫到的那个花色，整门都算。示例主打 ♥，所以 ♥ 整门都是主牌。

三部分加起来，示例这一副共 **18 张主牌**（♥5 已经在「四张 5」里数过，不重复）：

```widget
主牌分组卡墙 · 三组并排，每组带标题与张数，全部亮金边
  王      （2 张）： 大王 小王
  级牌    （4 张）： ♠5 ♥5 ♣5 ♦5
  ♥ 整门  （12 张）：♥2 ♥3 ♥4 ♥6 ♥7 ♥8 ♥9 ♥10 ♥J ♥Q ♥K ♥A
  合计 18 张
```

**如果叫的是「无主」，第 3 部分就没了**，主牌只剩 6 张：双王 + 四张级牌。同一手牌，主打花色不同，你的强牌会从 18 张掉到 6 张——这就是叫牌挑花色的意义。

```widget
两种将牌对照（沿用现有金边对照组件，但示例换成「整副牌的分类」）
  本副：级牌 5 · 主打 ♥ → 18 张主牌
  本副：级牌 5 · 无主   → 6 张主牌（只有双王与四张 5 亮金边）
  附注：无主时四张级牌完全相等，主牌大小只剩「四张 5 < 小王 < 大王」
```

**主牌内部也分大小**，从大到小：

```widget
CardRow size=md + 序号标注
  大王 → 小王 → ♥5 → ♠5 ♦5 ♣5 → ♥A
```

| 顺序 | 叫什么 | 说明 |
| --- | --- | --- |
| 1 | 大王 | 最大的一张 |
| 2 | 小王 | |
| 3 | **主级** | 主花色里的那张级牌（示例 ♥5） |
| 4 | **副级** | 另外三门的级牌（示例 ♠5 ♦5 ♣5），**三张完全一样大**，平张时先出的赢 |
| 5 | 主花色普通牌 | ♥2 到 ♥A（跳过 ♥5，它是主级） |

**副牌那边，每一门都「跳过级牌」。** 级牌 5 已经归主牌，所以副牌里根本没有 5 这张牌：♣ 这一门是 ♣2 ♣3 ♣4 ♣6 ♣7 … ♣A。**♣4 的下家直接就是 ♣6，它们是连着的。**

```widget
CardRow + 标注
  ♣2 ♣3 ♣4 ♣6 ♣7 ♣8 ♣9 ♣10 ♣J ♣Q ♣K ♣A
  标注：♣5 不在这一门（它归主牌）
```

**顺子可以跨过「主花色 → 级牌 → 王」这个边界**，因为它们在主牌里本来就是相邻的：

```widget
CardRow size=md + 标注
  ♥Q ♥K ♥A ♠5 ♥5
  标注：一条合法的 5 张主牌顺子
  附注：一条主牌顺子里最多只能有一张副级——三张副级完全相等，彼此不算相邻
```

## 4. 叫牌：谁坐庄、打什么、要得多少分

叫牌一次定下三件事：**庄家是谁、将牌是什么、庄家要得多少分**。

```widget
叫牌规则卡（列表或表格）
  · 从 40 分起叫，每次至少加 5 分
  · 可以一次跳很高（40 → 60），没有上限、没有加倍
  · 分数优先比大小；分数一样时比花色：♣ < ♦ < ♥ < ♠ < 无主
  · 也可以「不叫」
```

**什么时候结束**：**连续两家不叫**，最后叫的那个人成交；如果三家一起不叫，这一副作废重发——级别不变，只换下一家发牌。

看一段真实成交的叫牌（发牌人是你）：

```widget
叫牌序列 chips（沿用现有组件）
  你 40♣ ｜ 阿豪 45♥ ｜ 小美 不叫 ｜ 你 不叫
```

→ **阿豪 45♥ 坐庄**：主打 ♥、本副级牌是阿豪的 5、**阿豪必须抓够 45 分才算打成**。

**叫牌是「认领责任」。**成交之后你一个人对两家，叫多少就至少要抓多少。

所谓「六十分」，便是在长时间的试验中找到的平衡：一般而言，平均成交分数和最终获得分数的平均值大概是这个数。

**升级只看你实际抓了多少分，跟叫了多少分没关系，这和桥牌是不一样的**。叫 45 打成、拿到 75 分，和叫 75 打成、拿到 75 分，升级完全一样；而两种情况拿到 70 分，则就一胜一败了。由此得出两条基本结论：

- **正常情况不跳叫**。别人不拦着你，自己多承诺 5 分百害而无一利。
- **牌差建议不叫**。三家全不叫只是重发，你一分不亏；有人接了你就当闲家，队友可能更强，压力给到庄家。

当然，叫牌阶段也有一些心理博弈：

1. **「阻击叫」**：对手叫到 ♥65，你明明知道自己打 ♠65 胜算不大，但是你认为对手牌力较强，于是你叫 ♠65，逼着对手拿 ♥70 来压你。这样，只要他抓不到 70，欠的分就更多，你就能升更多的级；而如果对手不接了给你打 ♠65，你最后打到 45 输两级，也比对手打到 80 赢四级好。当然，也有可能你最后打到 25，这种惨败的可能性就是需要承担的代价了。
2. **位置决定压力**：连续两家不叫就定案，所以上家叫完，你不叫，就把压力给到下家——他不抬，就得让上家以较低的压力打；他继续叫，就有可能砸到自己手上。
3. **比分不同，风险偏好也该不同**：落后时更该冲高分；领先时叫稳一点，别把机会送出去。

最后，什么样的手牌值得叫高？**长套多**（某一门牌特别多）、**常主多**（双王与级牌都在你手上）。四门平均又没常主时，40 分都可能守不住。

## 5. 埋底：庄家的那 3 张

庄家把底牌 3 张收进手里，一共 20 张，然后**扣 3 张埋回去**。这 3 张在算账之前，另外两家都看不到。

```widget
HandFan · 20 张手牌扇形（真实张数）
  环境行：本副：级牌 5 · 主打 ♥（金边 = 主牌）
```

```widget
CardRow size=md · 示例底牌
  ♥5 ♦5 ♠7  → 共 10 分
```

**底牌的分不会消失**，最后按这个倍数记到庄家账上，倍数就是**最后一轮每家出了几张**：

| 最后一轮 | 倍数 |
| --- | --- |
| 每家 1 张 | ×1 |
| 每家 2 张 | ×2 |
| 每家 3 张 | ×3 |

- 最后一轮**庄家赢** → 加分，叫**保底**（超过一百也可以）。
- 最后一轮**闲家赢** → 扣分，叫**抠底**（扣成负数也可以）。

所以埋分是双刃剑：埋进去 10 分，保底就白拿 `10 × 张数`，被抠底就倒扣一样多。如果牌足够好，常见打法便是**把分埋掉、把大牌留在手上护底**，并且**最后一轮尽量多出牌**，例如 3 张顺子 × 20 分底牌 = +60 分，甚至可能直接逆风翻盘。

## 6. 打牌：领出、跟牌、杀牌

一轮里三家各出一次，赢的人领下一轮。一副牌一共 17 轮。

**① 领出**：出一张，或者出**同一门里大小相邻的连牌**（2 张及以上）。不允许甩牌。

```widget
正例/反例对照（CardRow + ✓/✗）
  ✓ ♠9
  ✓ ♠9 ♠10 ♠J ♠Q
  ✓ ♥2 ♥3（♥ 是主牌门）
  ✗ ♠9 + ♠J（中间缺 ♠10，不相邻）
  ✗ ♠9 ♠10 ♠J ♠Q + ♥2（混门）
  ✗ ♣6 + ♦8（混门）
```

**② 跟牌**：必须**同一门、同一张数**。如果这一门不够张数，就先把这一门全部出光，剩下的随便垫。

```widget
CardRow 对照
  上家领：♣3 ♣4 ♣6（3 张）
  你手里只有 ♣Q 一张 → 出 ♣Q + 任意两张
```

**③ 这一门够张数时，要「结构优先」：必须先把最长的那段连牌拿出来。**

```widget
[可交互] TryPlay id=follow · 跟牌（结构优先）
  上家领出：♣8 ♣9 ♣10 ♣J（4 张）
  我的手牌：♣3 ♣4 ♣6 ♣Q ♣K ♠9 ♥2
  本副：级牌 5 · 主打 ♥
```

你手里 ♣ 有 5 张，够跟 4 张。有两种拆法：`♣3-4-6` + `♣Q-K`，或者 `♣Q-K` + 两张散牌。**规则要求前者**：先把最长的 3 连拿出来，再随便配 1 张。所以正确答案是 `♣3-4-6 + ♣Q`（或 `+♣K`）。

```widget
TrickCluster 对照
  上家：♣8-9-10-J
  你：  ♣3-4-6 + ♣Q
```

> **为什么要有这条规则**：不然你可以永远用「大牌 + 小牌」的组合把长套拆开藏着，跟牌就成了随便选牌。

**④ 一轮归谁**，得同时满足三条：

1. **张数一样**（上家领 4 张，你也得出 4 张）；
2. **要么同门、而且比上家的大**；**要么是主牌连牌**（主牌天然压副牌，张数一样就行）；
3. 张数不同、或结构不同（比如人家出 `3 连 + 1 张`，你出 `2 连 + 2 连`），**都不能赢**——只能算垫牌。

大小完全一样时（比如两张副级牌碰上），**先出的赢**。

**⑤ 缺门**：某一门一张都没有时，你有两条路——用**同样张数的连续主牌**杀牌赢下这一轮，或者垫掉没用的牌。**垫牌不管多大都不能赢。**

```widget
[可交互] TryPlay id=ruff · 缺门杀牌
  上家领出：♠7 ♠8 ♠9（3 张）
  我的手牌：♥3 ♥4 ♥6 ♣2 ♣3 ♦4
  本副：级牌 5 · 主打 ♥
```

你一张 ♠ 都没有。`♥3-4-6` 是三张连续主牌（♥5 是主级、比它们都大，所以 ♥4 与 ♥6 之间是连的），能杀掉这一轮；`♣2 ♣3 ♦4` 是垫牌，不能赢。

## 7. 三条最值钱的推论

**① 常主永远最大。** 双王、主级、副级合称**常主**，任何副牌连牌都杀不过它们。所以一副副牌大牌看着吓人，遇到最低的三张主牌连牌照样输：

```widget
TrickCluster 对照
  环境行（金色小字）：本副：级牌 5 · 主打 ♥（♠ 是副牌；♥ 与四张 5、双王都是主牌）
  领出：♠A ♠K ♠Q（副牌里最大的三张）
  赢家：♥2 ♥3 ♥4（主牌里最小的三张）  ← 带「赢墩」标记
```

**② 副牌顺子跳过级牌，所以「看着缺一张」的连牌是合法的。** 级牌 5 归主牌，♣ 这一门从 ♣4 直接到 ♣6，所以 **♣3-4-6 三张是连着的**，可以当顺子出。反过来，♣3 和 ♣9 中间隔着 ♣4 ♣6 ♣7 ♣8，**不能一起出**。

```widget
正例/反例（CardRow + ✓/✗）
  环境行（金色小字）：本副：级牌 5 · 主打 ♥（级牌 5 已归主牌，三门副牌的 5 都空了）
  ✓ ♣3 ♣4 ♣6（♣5 是级牌，不在这一门）
  ✗ ♣3 + ♣9（同门，但不相邻）
  · ♥3 ♥4 ♥6 同理：♥5 是主级，位置比这些 ♥ 都高
```

**③ 分牌晚出，或者垫给队友。** 5 / 10 / K 谁赢走算谁的。手里有分牌时，尽量等一轮自己能赢的再出；跟不出门时，优先把分垫给队友（庄家正好相反：想尽办法把分收进自己手里）。**最后一轮一定要抢**——只有赢了最后一轮才有保底 / 抠底。

## 8. 算账：打成没有、谁升几级

**一条式子：**

```widget
结算算式组件（沿用现有大数字排版）
  墩分 55  ＋  底牌 10 分 × 末轮 2 张  ＝  最终得分 75
```

同一副牌，最后一轮谁赢，结果完全不同：

- 最后一轮**庄家赢**（保底）→ `55 + 10 × 2 = 75`
- 最后一轮**闲家赢**（抠底）→ `55 − 10 × 2 = 35`

**最终得分 ≥ 叫的分数 → 打成**（正好相等也算打成）。上例叫的是 45：保底 75 ≥ 45，打成；被抠底 35 < 45，打输。

```widget
结算对照卡（沿用现有绿/红两张卡）
  保底：55 + 10×2 = 75 ≥ 45 → 打成
  抠底：55 − 10×2 = 35 < 45 → 打输
```

> **这就是最后一轮关键所在**：底牌只有 10 分，却能在最后一轮的输赢之间摆动 ±20 分。同一副牌，从「庄家打包升 3 级」直接翻成「庄家打输、两家各升 1 级」。

**闲家要抓够多少分才能把庄家打输？** 不是 `100 − 45 = 55`：

```widget
闲家门槛 · 一句话版（两个数值由 settle.ts 算出，别手写）
  不是 100 − 45 = 55：底牌那 10 分不进任何人的轮，只走庄家的账。
  保底时闲家要严格超过 65 分；抠底时超过 25 分就够。
```

一句话：**埋了分，就等于把自己的命门押在最后一轮上。**

但是注意：如果前期分差太大，庄家保底/闲家抠底也可能无力回天。若庄家不埋分，那最后一轮便没有什么特殊的用处。

**打成 → 庄家升级。** 升级只看最终得分：

| 最终得分 | 庄家升级 |
| --- | --- |
| 40 / 55 | 1 级 |
| 60 / 65 | 2 级 |
| 70 / 75 | 3 级 |
| 80 / 85 | 4 级 |
| ≥ 90 | 5 级起，每多 5 分再 1 级 |

**「升 N 级」= 从你现在的级别往前推 N 级，跨过 A 就进位到下一轮的 2：**

```widget
LevelBadge 示意 + 两条步进
  5(+0) 升 3 级 → 8(+0)（同一轮内推进）
  A(+0) 升 2 级 → 3(+1)（跨过 A，轮数 +1）
```

上例：阿豪是 `5(+0)`，保底拿 75 分 → 升 3 级 → **`8(+0)`**。

**打输 → 庄家级别不变，两家闲家各升 `上取整(差 / 10)` 级**，其中 `差 = 叫的分数 − 最终得分`：

```widget
差值 chips（沿用现有渲染）
  差 5 → 各升 1 级 ｜ 差 15 → 各升 2 级 ｜ 差 35 → 各升 4 级
```

上例抠底：差 = 45 − 35 = 10 → 两家各升 1 级。

**什么时候结束**：如果想要打得长一点（约 20 局），任意**两位玩家**达到 `2(+2)`，或者任意**一位玩家**冲到 `2(+3)`，对局结束，总进度最高的那位是冠军。当然，也可以协商任何时候结束。
